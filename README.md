# Студия дипломов

[Открыть студию в браузере](https://cube-diploma-studio.queueless.workers.dev/)

Веб-приложение и версия для Windows x64 создают сертификаты участников и волонтёров, призовые дипломы и именные бейджи для соревнований по спидкубингу.

## Работа в приложении

1. Откройте сайт или запустите **CubeDiploma-2.exe**. На сайте CSV, имена и подписи обрабатываются в браузере. PDF скачивается на ваше устройство. После загрузки офлайн-копии этот же адрес можно открыть и без интернета.
2. В разделе **Соревнование** замените название и дату. Программа печатает дату в том виде, в котором вы её ввели, в том числе диапазон дат.
3. В разделе **Организаторы и подписи** задайте имена и роли подписантов для сертификатов и призовых дипломов. Для каждого можно выбрать изображение подписи в PNG или JPEG. Шаблон вмещает до пяти подписантов.
4. Для сертификатов участия выберите **Участие** и загрузите регистрационный CSV с заголовками. В выгрузке WCA имена берутся из столбца `Name`. При необходимости выберите другой столбец. Каждая непустая строка имени даёт одну страницу. Порядок совпадает с CSV, одинаковые имена сохраняются. Список можно отредактировать вручную.
5. Для сертификатов волонтёров откройте **Волонтёры**. Загрузите отдельный CSV, введите имена вручную или нажмите **Добавить волонтёров из бейджей**, чтобы перенести людей со статусом `VOLUNTEER`. Список волонтёров сохраняется отдельно. Название соревнования, дата и подписи общие для обоих видов сертификатов.
6. Для призовых дипломов выберите **Призовые места**, отметьте дисциплины и при желании внесите имена и результаты. Для каждой дисциплины в PDF идут три страницы подряд, с первого места по третье. Пустые строки можно заполнить от руки.
7. Проверьте страницы в предпросмотре и нажмите **Скачать PDF**. Браузер сохранит один файл для выбранного режима.

## Бейджи

1. Выберите **Бейджи** и проверьте название соревнования и дату. Эти два поля общие для всех документов.
2. В разделе **Список для бейджей** нажмите **Вставить имена** и вставьте по одному имени на строку. В поле **Статус для новых бейджей** выберите статус для всей группы, например **VOLUNTEER**, и нажмите **Применить**. По умолчанию выбран **COMPETITOR**. Чтобы добавить группу к уже заполненному списку, нажмите **Изменить список** и допишите имена с новой строки. У людей, которые уже были в списке, сохраняются прежние статусы. Бейджи печатаются в порядке строк, полные тёзки сопоставляются по очереди.
   Также можно загрузить CSV или добавить человека вручную. В строке бейджа можно исправить имя и выбрать **DELEGATE**, **ORGANIZER**, **GUEST** или **VOLUNTEER**. У каждого статуса свой цвет. При повторном импорте файла с тем же именем и столбцом сохраняются правки у совпадающих участников. Добавленные вручную люди остаются в списке бейджей.
3. Введите ширину и высоту готового бейджа в миллиметрах. Поля задают свободное место от края A4, а зазор — расстояние между соседними бейджами. Программа учитывает поворот на 90°, выбирает ориентацию листа и формирует один PDF. При размере 75 × 100 мм, полях 5 мм и нулевом зазоре на альбомном A4 помещается шесть вертикальных бейджей. Для сложного формата, когда расчёт ещё не подтверждает математический максимум, рядом с количеством появится пометка «Лучшая найденная раскладка».
4. Вставьте общую ссылку в поле для QR-кода. Код появится в нижней левой части каждого бейджа. Если оставить поле пустым, бейджи можно напечатать без кода.
5. Нажмите **Скачать PDF**. Для печати выберите **A4** и **Фактический размер / 100%**, чтобы ширина и высота бейджа на бумаге соответствовали введённым значениям.

Сайт сохраняет черновик в хранилище текущего браузера. Для продолжения откройте тот же адрес в том же профиле. Очистка данных сайта удаляет сохранённый черновик. В Windows-приложении черновик хранится в `%LOCALAPPDATA%\CubeDiploma\draft-v2.json`. При первом запуске оно подхватывает черновик предыдущей версии, если он есть.

Список из 17 дисциплин соответствует [пункту 9b регламента WCA](https://www.worldcubeassociation.org/regulations/#9b) на 21 ноября 2026 года. Обе версии читают список из `assets/events.json`.

## Веб-версия

Публичная студия обновляется через Cloudflare Workers Builds при каждом push в `main`. Cloudflare запускает `npm test && npm run build` из корня репозитория, затем публикует успешную сборку командой `npx wrangler deploy`. Статус виден в проверках коммита на GitHub и в разделе **Deployments** проекта Cloudflare. Чтобы перейти на опубликованную версию в уже открытой студии, обновите страницу.

Для разработки используйте Node.js 22.13+ или 24 LTS. Выполните команды из корня репозитория.

```sh
npm ci
npm test
npm run dev
```

Команда `npm run build` собирает статические файлы в `dist-web/`. Команда `npm run preview` открывает локальную копию этой сборки. Для публикации в своём аккаунте Cloudflare выполните `npx wrangler login`, затем `npm run deploy`. Cloudflare раздаёт интерфейс, шаблоны и шрифты. В фоне браузер разбирает CSV, рассчитывает раскладку и формирует PDF. Предпросмотр показывает страницу самого PDF.

## Windows-версия

Для разработки используйте Python 3.12 x64 в Windows. Выполните команды из папки с этим файлом.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

Чтобы собрать исполняемый файл, выполните следующие команды.

```powershell
.\.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3
.\.venv\Scripts\python.exe -m PyInstaller CubeDiploma.spec
```

Программа появится в `dist\CubeDiploma-2.exe`. В папке `assets` лежат элементы встроенных шаблонов. За сертификаты отвечает `pdf_engine.py`, за оформление бейджа — `badge_art.py`, за печатные листы A4 — `badge_sheets.py`.
